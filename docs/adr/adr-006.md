# ADR 006 – Implémentation d'une queue d'ordres à traiter

## Statut

Acceptée

## Contexte

Afin de pouvoir accepter des ordres même en cas de pic de charge ou de panne temporaire, il nous faut pouvoir les stocker avant traitement.

## Décision

On réalise le circuit suivant:

- passerelle API crée un nouvel ordre via le service Order Service
- passerelle API transmet une demande de traitement avec seulement l'id de l'ordre au service Order Processor
- le service Order Processor ajoute l'id de l'ordre dans la queue
- un worker dédié au traitement des ordres lit la queue et traite les ordres un par un
